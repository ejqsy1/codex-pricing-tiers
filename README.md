## 为什么你查到的“Codex 价格”总对不上

搜这个词的人常会遇到三个坑。

第一，Codex 本身不单独收费。你付的是 ChatGPT 订阅的钱，很多标题写着“Codex 价格”的文章，实际在讲 ChatGPT 各档套餐。

第三，OpenAI 调整得太频繁。Pro 从“比 Plus 高 5 到 20 倍用量”的单档描述，变成了 100/200/500 三档定价；Business 年付价从 25 美元降到 20 美元；团队版还一度上线了“按量付费、不限速”的 Codex 专属席位，几个月后又对新用户关上了门。半年前的攻略放到现在，数字很可能已经不准。

## Plus（$20/月）：大多数人的答案

Plus 是公认的起步推荐档。网页端、终端 CLI、IDE 插件、iOS 全入口都有，云端后台任务、GitHub 自动代码审查这类订阅专属功能也在，新模型第一时间能用。

唯一的悬念是额度够不够。轻度到中度使用，一周下来很难触顶；但如果你的日常是让 agent 连续几小时啃大项目、跑长会话，5 小时窗口内的余量会掉得飞快。撞了限额不用慌，可以先买积分续命，不必直接升档。

## Pro 分了三档：100、200、500 美元差在哪

Pro 现在按额度分档。Pro 100（100 美元/月）约 5 倍 Plus 额度；Pro 200（200 美元/月）介于两者之间，官方对各档倍数的说法调整过几次，下单前以定价页为准；Pro 500（500 美元/月）给约 25 倍额度，附带 Ultrafast 版快速模型——token 生成速度快 8 倍，但额度消耗同样是 8 倍。

有第三方算过一笔账：把 25 倍额度除以 8 倍消耗速度，全天满负荷跑 Ultrafast，实际约等于 3 倍 Plus 的量。换句话说，Pro 500 卖的是“等不起”而不是“用得多”。按小时收费的顾问、盯在线调试的人，8 倍速度能直接折成钱；瓶颈在思考时间而不是响应速度的人，100 美元那档明显更实际。

## 团队走 Business：年付 20 美元/人是怎么来的

Business 年付 20 美元/用户/月（月付 25 美元，2 席起订）。这个价格是官方今年主动从 25 美元降下来的。席位自带 Plus 量级的 Codex 额度，外加团队工作区、管理员后台、SSO/MFA，以及“数据默认不用于训练”。

今年春天官方短暂开放过按量付费、不限速的 Codex 专属席位，6 月下旬起已停止向 Business 新用户开放，老席位不受影响。算总账的话，五个人的团队年付合计每月约 100 美元，换来五个独立的 Plus 级窗口——如果大家的用量比较分散，五个小窗口通常比一个大窗口更抗撞顶，因为高峰期不会挤在同一个人身上。

## 限额到底怎么算：5 小时窗口、周上限和积分

本地消息和云端任务共享一个 5 小时滚动窗口（中间短暂放开过一次，后来恢复），窗口之上另有每周上限，官方没有公开具体数字。消息数不是死数——同一个档位下，读一个小文件的消耗和重写一整个模块能差出数量级。

## 订阅和 API key 是两套账

同一个 Codex，登录方式决定计费逻辑。

用 ChatGPT 账号登录走“订阅 + 额度”：固定月费、封顶可控，有云端功能，新模型第一时间能用。用 API key 登录走“按 token 实时扣费”：没有月费也没有窗口，账单事后才知道，云端功能基本没有，新模型也慢一步。以 GPT-6.1 Sol 为例，API 价约是输入每百万 token 2 美元、输出 10 美元，一个读写 20 万 token 的任务算下来 3 毛美元左右。

结论很简单：人用订阅，机器用 API。半夜让脚本批量跑任务、接 CI 流水线，才轮到 API key 出场。

## 几个让额度更耐用的习惯

- **提示写具体**。“改进这个项目”会让它满仓库翻文件猜意图；“改 src/auth.ts 的 login 函数，加输入校验”能省掉一大截探索开销。
- **给 AGENTS.md 瘦身**。这份项目说明每条消息都会被塞进上下文，把根目录几百行的巨无霸改成按子目录分层的小文件，输入量降得很快。
- **MCP server 按需开**。每接一个外部工具，它的描述就常驻每条消息的上下文，用不上就是白烧。
- **常规任务切轻量模型**。同档位下，Luna 这类轻量模型的消息数区间是重模型的几十倍，日常改代码完全够。
- **换任务用 /new 开新会话**，别让上午的上下文跟着你耗到下午。
- **随手用 /status 查剩余限额**，网页端的用量面板能看跨设备的全局消耗。

## 常见问题

**Codex 会员一个月到底多少钱？**
没有独立会员，随 ChatGPT 套餐走：免费 0 美元、Go 8 美元、Plus 20 美元、Pro 100/200/500 美元、Business 年付 20 美元/用户，企业版联系销售定制。

**免费版能用 Codex 吗？**
能摸到，用不痛快。Free 有受限额度，CLI 配自己的 API key 也能跑，但 token 费自理。想正经用，从 Plus 开始。

**额度用完了怎么办？**
两条路：买积分续（约 0.04 美元/个），或者升档。如果积分的日常开销已经超过下一档的差价，升档更划算。

**生成的代码还要人审吗？**
要。这类 agent 偶尔会“自信地做错”——改动看起来干净漂亮，实际没对上需求。把它当快速靠谱的同事，但合并前照样要自己过一遍。

**Plus 的额度够用吗？**
看强度。以 GPT-6.1 Sol 为例，Plus 每 5 小时大约 15–160 条消息，轻度到中度使用很难触顶；如果你的日常是让 agent 连续跑几小时的大重构，Plus 通常会在下午停下脚步。

回到最初的问题：Codex 会员的价格区间就是 0 到 500 美元/月，中间每一档对应一种使用强度。想清楚自己每周会撞几次窗，再对着表下单，基本不会花冤枉钱。
